# LearnTracker

**LearnTracker** is a learning tracker app that helps users track their learning progress. It supports three types of users: **Admin**, **Mentor**, and **Mentee**.  

- **Admin**: Create roadmaps, assign mentees to mentors, manage resources.  
- **Mentor**: Modify roadmaps, add resources for mentees, track mentee progress.  
- **Mentee**: View roadmaps, log progress, access learning resources.  

---

## Features

- Login / Signup UI
- Mentee dashboard with roadmap and progress tracking
- Mentor feedback system
- Admin management of users and roadmaps
- Resource management for learning topics

---

## Tech Stack

- React + TypeScript  
- TailwindCSS  

---

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/learntrack.git
cd learntrack
````

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Start the development server:

```bash
npm start
# or
yarn start
```

4. Open in your browser:

```
http://localhost:5173
```
